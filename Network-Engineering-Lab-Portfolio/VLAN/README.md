# VLAN Technologies

## Overview

This section of the portfolio focuses on network segmentation and VLAN technologies. The labs demonstrate how VLANs improve scalability, security, and network management within enterprise environments.

## Labs Included

### Creating VLANs
Implementation of VLAN-based segmentation to logically separate network traffic within a switched environment.

### VLAN Trunking
Configuration of trunk links to transport traffic for multiple VLANs between switches.

### Router-on-a-Stick
Implementation of Inter-VLAN Routing using a router and 802.1Q trunking.

### Inter-VLAN Routing (Layer 3 Switch)
Configuration of a multilayer switch to route traffic between VLANs without requiring an external router.

### VTP
Implementation of VLAN Trunking Protocol to centralize VLAN administration and simplify switch management.
